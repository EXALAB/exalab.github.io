Linux Environment Installation

LinuxBox allows users to install and run Linux environments such as Ubuntu, Debian, and Kali Linux.

During installation, LinuxBox may download files from external sources, such as GitHub-hosted resources.

LinuxBox does not collect or upload any personal information during this process.
All installed Linux environments and related files remain on your device.


External Services

Google AdMob (advertising)

GitHub (LinuxBox resources)

These services operate under their own privacy policies and terms.


Data Security

LinuxBox does not maintain a server that stores user personal data.

The security of installed Linux environments and files stored on your device depends on your device security settings.


Children's Privacy

LinuxBox does not knowingly collect personal information from children.
